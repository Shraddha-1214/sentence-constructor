
 Sentence Constructor

A simple web application built using Flask that helps users practice sentence construction by selecting the correct words for blanks.



 Features

- Display sentences with missing words.
- Users can view multiple options for each blank.
- Neat and simple frontend using HTML & CSS.
- JSON-powered questions for easy updates.



 Tech Stack

- Python 3
- Flask
- HTML/CSS
- JSON


🚀 How to Run Locally
Clone the repository:

bash
